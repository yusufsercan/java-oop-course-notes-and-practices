# 🚀 Java & OOP Course Notes & Practices

This repository contains Java code examples, OOP implementations, and laboratory exercises developed during my university coursework and personal study sessions.

> ⚠️ **Note:** The code in this repository documents my ongoing learning journey in Object-Oriented Programming. The primary goal is to master OOP principles, understand JVM internals, and establish solid software architecture fundamentals.

---

## 📁 Repository Structure

* **01-Basics-and-Syntax:** Fundamental Java syntax, primitive types, control flows, loops, and Scanner input handling.
* **02-Classes-and-Objects:** Object-Oriented fundamentals, class blueprints, heap/stack memory references, constructors, and the `this` keyword.
* **03-Encapsulation-and-Inheritance:** Access modifiers (`private`, `protected`, `public`), getter/setter encapsulation, code reusability via inheritance (`extends`), and constructor chaining (`super`).
* **04-Polymorphism-and-Interfaces:** Method overriding (`@Override`), runtime polymorphism, abstract classes, and multiple inheritance through interfaces.
* **05-Collections-and-Exceptions:** Robust error handling (`try-catch-finally`, custom exceptions), and Java Collections Framework (`ArrayList`, `HashMap`, `HashSet`).
* **06-Lab-and-Challenges:** Academic laboratory assignments, challenge exercises, and midterm/final study problems.
