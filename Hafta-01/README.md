# 📚 Week 01: Introduction to Object-Oriented Programming & Java Fundamentals

This directory contains the **Week 01 Lecture Notes and Laboratory Practices** for the *Object-Oriented Programming* course at **Karadeniz Technical University (KTU) Of Faculty of Technology - Department of Software Engineering**.

The primary objective of this module is to bridge procedural/structured programming concepts from C into Java's Object-Oriented (OOP) architecture, with a particular focus on memory layout models (Stack vs. Heap semantics).

> **Note:** Detailed code annotations and technical exam notes within this directory are maintained in Turkish to align directly with academic coursework.
