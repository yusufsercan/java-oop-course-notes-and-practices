1. 'null' DEĞERİ NEDİR? (BELLEK BOYUTU)

--------------------------------------------------------------------------------

- Bir referans (işaretçi) değişkeninin bellekte hiçbir somut nesneyi 

  göstermediğini belirten özel bir anahtar kelimedir.

- Otel Benzetmesi: 

  Elinizde manyetik bir kart vardır (Stack'teki referans değişkeni), fakat kartın 

  içine hiçbir oda numarası kodlanmamıştır (Heap'te karşılık gelen nesne yoktur).



Kod Örneği:

    Ogrenci o3 = null;



Bellek Durumu:

    STACK (Yerel Değişkenler)        HEAP (Dinamik Nesne Alanı)

    +-----------------------+        +--------------------------+

    | o3 : null             | ----X  | (Bağlı hiçbir nesne yok) |

    +-----------------------+        +--------------------------+





================================================================================

2. NullPointerException (NPE) NEDİR? (C İLE KIYASLAMA)

--------------------------------------------------------------------------------

- Tanım: 'null' değerine sahip bir referans üzerinden bir özelliğe erişmeye 

  veya bir metodu çalıştırmaya kalktığınızda JVM tarafından fırlatılan 

  çalışma zamanı (runtime) hatasıdır.



Kod Tuzağı:

    Ogrenci o3 = null;

    o3.bilgiYaz(); // ÇÖKME! -> java.lang.NullPointerException



C Dilindeki Birebir Karşılığı:

    int *ptr = NULL;

    printf("%d", *ptr); // ÇÖKME! -> Segmentation Fault (Core Dumped)



* JVM Özeti: Java, adresi olmayan hayali bir nesnenin kapısını açamayacağı için 

  güvenlik gereği programı o satırda derhal durdurur.





================================================================================

3. SAVUNMACI KODLAMA (DEFENSIVE PROGRAMMING)

--------------------------------------------------------------------------------

Bir referansın dışarıdan (metot parametresi, veri tabanı vb.) 'null' gelme 

ihtimali varsa, işlem yapmadan önce mutlaka 'null denetimi' yapılmalıdır:



    if (o3 != null) {

        o3.bilgiYaz(); // Güvenli çalışma alanı

    } else {

        System.out.println("Hata: Ogrenci nesnesi henuz olusturulmamis!");

    }

4. NESNE DİZİLERİNDEKİ BÜYÜK YANILGI (KRİTİK VİZE KONUSU)

--------------------------------------------------------------------------------

İlkel tipler ile nesne tipleri dizilerde tamamen farklı davranır:



A) İlkel Tip Dizisi:

    int[] sayilar = new int[3]; 

    -> Bellekte 3 adet tamsayı alanı açılır ve varsayılan olarak [0, 0, 0] olur.



B) Nesne Dizisi:

    Ogrenci[] sinif = new Ogrenci[3];

    -> DİKKAT: Bu ifade 3 tane 'Ogrenci' NESNESİ ÜRETMEZ!

    -> Sadece 3 adet 'Ogrenci referansı' (kumanda) tutabilecek BOŞ BİR RAF açar.



    Bellekteki İlk Durum:

    sinif[0] -> null

    sinif[1] -> null

    sinif[2] -> null



ÖLÜMCÜL HATA:

    sinif[0].ad = "Ali"; // HATA! sinif[0] null olduğu için NullPointerException!



DOĞRU KULLANIM (Nesneleri Tek Tek Üretmek):

    sinif[0] = new Ogrenci(); // 1. nesne Heap'te oluşturuldu

    sinif[0].ad = "Ali";      // Artık güvenle erişilebilir!



    sinif[1] = new Ogrenci(); // 2. nesne oluşturuldu

    sinif[1].ad = "Ayse";

5. DİZİLERDE DÖNGÜ VE for-each KULLANIMI

--------------------------------------------------------------------------------

Nesne dizilerini gezerken C tarzı indeksli sayaçlar yerine Java'nın gelişmiş 

'for-each' döngüsü tercih edilir.



Kod:

    Ogrenci[] kucukSinif = { o1, o2 };



    double toplam = 0.0;

    for (Ogrenci o : kucukSinif) {

        toplam += o.ortalamaHesapla();

    }

    double sinifOrtalamasi = toplam / kucukSinif.length;



Avantajı:

- İndeks taşması (ArrayIndexOutOfBoundsException) riskini sıfırlar.

- Dizinin eleman sayısını el ile takip etme zorunluluğunu kaldırır.

6. TİPİK SINAV TUZAĞI (KOD OKUMA SORUSU)

--------------------------------------------------------------------------------

Soru: Aşağıdaki kod parçası çalıştırıldığında ne olur?



    Dikdortgen[] dizi = new Dikdortgen[2];

    dizi[0].genislik = 5.0;

    System.out.println(dizi[0].alan());



Yanıt / Analiz:

- 'new Dikdortgen[2]' satırı sadece 2 elemanlı referans dizisi açar; 

  elemanların başlangıç değeri null'dır.

- 'dizi[0]' henüz 'new Dikdortgen()' ile başlatılmadığından, 'dizi[0].genislik' 

  satırında program 'java.lang.NullPointerException' hatası vererek çöker.

- Ekrana herhangi bir alan veya sayı basılmaz.
